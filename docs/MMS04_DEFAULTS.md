# MMS-04 competition default profile (partial)

Static typed model defines 90-second qualifiers, 180-second finals and a
balanced 10,000-basis-point preliminary judging rubric. Audience voting,
battles, ensemble, improvisation, prompts and monetary functions are all
disabled by default; there is no required paywall.

These are local proposal values only. Actual venue policies and owner-approved
rubric, tenant overrides, persisted signed engine rulesets, chronological event
validation, audience voting, prize and wallet controls, and production rehearsal
are missing. Do not submit these values to engine writes without verified
capability, organizer authorization and reviewed event rules.
